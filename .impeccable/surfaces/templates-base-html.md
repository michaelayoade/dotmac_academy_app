# Academy application shell redesign

Mode: Operate

Scope: The authenticated shared shell and every Learner, Teaching, Admin, account, course, assessment, reporting, and lab surface that inherits it.

Audience and job: Learners complete learning work; instructors operate cohorts, teaching, assessment, reports, and labs; administrators operate admissions, identity, audit, messaging, and settings. Success is fast orientation, complete data visibility, and reliable task completion.

Constraints: Retain the Dotmac Academy header logo and name. Preserve every route, permission, button, form, link, field, status, table column, HTMX behavior, and factual product copy. Desktop and mobile must provide complete access to wide data. The supplied Stitch Academic Modernist package is the approved reference.

## Direction contract

THESIS: A calm Academic Modernist operations workspace: rigorous, legible, and quietly authoritative. It refuses both the generic floating-card dashboard and decorative academic nostalgia.

OWN-WORLD: Pale sage canvas, pure white working surfaces, Oxford forest controls, emerald state accents, hairline warm-grey structure, compact architectural radii, sturdy editorial headings, and crisp grotesk data text.

STORY: Each role lands in a familiar workspace, reads current state immediately, scopes dense data with ordinary controls, and completes the next operational action without losing context.

FIRST VIEWPORT: A 64px branded header anchors role tabs, search, notifications, and account. A persistent role sidebar names the workspace. The main canvas opens with a compact category kicker, decisive title, task description, visible primary actions, then real metrics or the most important working data.

FORM: User-pinned Academic Modernist Stitch reference; code-first translation across the existing Jinja product. Seed key: `user-pinned-academic-modernist-stitch-20261006`. Signature move: precise green status/progress signals and a single active-navigation rule connecting shell, tables, and task state.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
