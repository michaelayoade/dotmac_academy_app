## Prepared behavior

It permits only current admins, binds the person and role resource identifiers, requires one newly persisted role-grant outcome, appends the fixed `role.grant`/`person_role` event, and rechecks the same grant row at exit. An existing grant cannot manufacture a new grant event.

`assign_web_facilitator` and `bulk_enroll_web_roster` use the actual WEB cookie HMAC session without decoding JWT claims, with current instructor/admin role gates. They intentionally have no audit action. Bulk resolution is checked again after waits. `actor_is_admin` is a refreshed derived fact for the future roster owner; it is not an accepted argument or proof. The roster owner must preserve existing per-target admin guard priority and bulk per-email `admin_required` continuation.

`resend_web_account_invitation` fixes the existing WEB admin gate and target binding without inventing another event. The invitation owner retains its existing `account.invitation.completed` event and outcome checks; this wrapper is not wired into that owner here.

The whole yielded operation remains inside public Kernel `conflict_savepoint`. Request identity, Session identity, root, current actual `app.current_tenant` setting, tenant, issued instance, operation, resources, actor and exact session remain bound. Time is sampled after blocking locks and authority is refreshed before audit and exit. Copied contexts and substituted request/session/root/resources refuse. Context method errors poison exit even if caught inside the yield, preventing an outer commit from saving those operation changes. Kernel fatal root recovery remains authoritative. The context clears its entire private dictionary, including proof, digest, claims, rows and Request references, on every exit.

After savepoint rollback and Kernel root validation, existing `HTTPException`, `BadRequestError`, `ConflictError` and `NotFoundError` escape unchanged, preserving product 403/404/409 mappings and existing guard priorities. Unexpected internal/provider exceptions are sanitized. A hosted genuine-request canary asserts domain exception identity and caught outer-commit rollback.
